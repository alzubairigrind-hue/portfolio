# Portfolio Design References

Award-winning sites collected as design references for my portfolio (target look: bold, with animated effects).

- **Collected:** 2026-09-22
- **Awards source:** Awwwards [Portfolio winners](https://www.awwwards.com/websites/winner_category_portfolio/) and [Sites of the Month](https://www.awwwards.com/websites/sites_of_the_month/)

- **Owner's role:** copied from each site's own wording, checked on 2026-09-22

> An Awwwards "Developer Award" rates how well the site is built. It does **not** mean the owner is a developer.

## Notes

- Heavy 3D/WebGL (for example bruno-simon.com) is weeks of specialist work. Borrow the feel with typography, scroll animation and page transitions instead.
- Arabic is the default language. Letter-by-letter text effects may break Arabic letter joining. This is not verified yet; check before choosing any text effect.
